# esp-pluto-sdr
Independent ESP-IDF host component for PlutoSDR-compatible IIO radios. ESP32-P4 first, with radio control and IQ reception; OrcSDR is the first integration target.

Experimental driver implementation is on the development branch. See
[DRIVER.md](DRIVER.md) for APIs, host checks, ESP-IDF integration and current limits.

Developer documentation: [Driver API reference](docs/API.md).
